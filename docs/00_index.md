# Enterprise MVP Docs Index

## Purpose
This folder contains the SDLC documents for the Enterprise MVP: a multilingual (language-first) conversational AI voice agent for e-commerce support, with WhatsApp Business API continuation, and a pluggable telephony adapter layer supporting multiple providers (Twilio, Exotel, SIP/Asterisk, Genesys, etc.).

## Documents
- [01_prd_mvp.md](./01_prd_mvp.md): Enterprise MVP product requirements and acceptance criteria
- [02_architecture_mvp.md](./02_architecture_mvp.md): Enterprise reference architecture with telephony adapter layer
- [03_api_contracts.md](./03_api_contracts.md): Internal API contracts and telephony adapter contracts
- [04_data_model.md](./04_data_model.md): Data model for enterprise scale
- [05_test_plan.md](./05_test_plan.md): Test strategy and validation checklist
- [06_delivery_plan.md](./06_delivery_plan.md): Delivery phases, review gates, and customer prerequisites
- [07_backlog.md](./07_backlog.md): Epics/stories for implementation planning
- [08_telephony_adapters.md](./08_telephony_adapters.md): Telephony adapter specifications and provider guides
